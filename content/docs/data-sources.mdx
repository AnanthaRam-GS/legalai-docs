LegalAI uses four kinds of data: court judgments for retrieval, official crime statistics for analytics, a comparative IPC-to-BNS mapping, and the official section headings of the criminal Acts. Each keeps its provenance.

## Judgments

| Item                | Detail                                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------ |
| **Source**          | Indian Kanoon, through its documented API (no website scraping)                                        |
| **Corpus**          | 70 trusted, human-reviewed criminal judgments: 48 High Court, 14 Supreme Court, 8 district or sessions |
| **Size**            | 4,195 paragraphs in 1,356 chunks                                                                       |
| **Provenance kept** | Source URL, source document ID, retrieval time, SHA-256 digest                                         |
| **Attribution**     | Judgment data sourced from the Indian Kanoon API                                                       |

Candidates were filtered for criminal law, pre-screened and reviewed by a person before acceptance. A separate validation set covers judgments after 1 July 2024 to exercise BNS and BNSS handling. The corpus is intentionally small for now; the plan scales it in stages only after metadata quality and retrieval behaviour are validated.

| Item              | Detail                                                                                                        |

| **Publication**   | _Crime in India 2024_, Volume I, National Crime Records Bureau, Ministry of Home Affairs, Government of India |
| **Table**         | Table 1A.4, IPC/BNS Crimes (Crime Head-wise and State/UT-wise), 79 table pages                                |
| **Obtained from** | The official NCRB publication page; no mirror or third-party copy was used                                    |
| **Integrity**     | The extractor refuses any file but the recorded one, checked by SHA-256                                       |
| **Rows**          | 6,201: 159 crime heads × 39 State/UT and total rows                                                           |

2024 is the first edition reported under the BNS, and the table prints the BNS head beside the IPC head, so both are stored. Counts are registrations, not convictions or acquittals. Crime heads keep their printed names; only one evident misprint has a display label, and two printed section notations are parsed in corrected form, each with documented evidence.

## IPC-to-BNS mapping

| Item         | Detail                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| **Sources**  | NCRB CYTRAIN section correspondence table and CYTRAIN BNS text; NCRB _Crime in India 2024_, Table 1A.4 |
| **Accessed** | 4 September 2026 (CYTRAIN); NCRB rows added on 26 October 2026                                         |
| **Rows**     | 438: 370 from CYTRAIN (367 direct, 3 repealed) and 68 printed in the NCRB table                        |
| **Status**   | <StatusBadge status="pending-approval" label="Unreviewed" /> pending legal review                      |

The mapping is a comparative reference, not statutory text. Every row records its source, and NCRB rows also record the printed table page. A full cross-check of the pairs printed in the corrected NCRB table found 68 IPC sections with no CYTRAIN row and no contradiction; those 68 rows were added with their NCRB attribution. NCRB prints which sections a crime head counts, not whether a provision was carried over directly, split or merged, so their change type is shown as "Not specified" rather than guessed. CYTRAIN rows that cover several IPC sections under one group label are not split, because the CYTRAIN site was unreachable when last tried.

## Official section headings

| Item          | Detail                                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Source**    | India Code, the official legislative repository, at `https://indiacode.gov.in` (the former `indiacode.nic.in` now redirects there) |
| **Retrieval** | India Code's public DSpace REST API (`/server/api`), over HTTPS, on 12 November 2026; no other site was used                       |
| **Stored**    | Section numbers and headings only; the Acts' PDFs and section texts are not stored                                                 |
| **Status**    | <StatusBadge status="pending-approval" label="Unreviewed" /> spot-checked, not reviewed by a lawyer                                |

| Act                                | Read from                                         | Headings                                  |
| ---------------------------------- | ------------------------------------------------- | ----------------------------------------- |
| Indian Penal Code, 1860            | The Act's PDF: arrangement and body cross-checked | 548, plus 21 omitted or repealed sections |
| Indian Evidence Act, 1872          | The same                                          | 181, plus 1 repealed section              |
| Bharatiya Nyaya Sanhita            | India Code's per-section records                  | 358 (complete)                            |
| Bharatiya Nagarik Suraksha Sanhita | India Code's per-section records                  | 531 (complete)                            |
| Bharatiya Sakshya Adhiniyam        | India Code's per-section records                  | 170 (complete)                            |
| Code of Criminal Procedure, 1973   | —                                                 | **None: a known gap** (below)             |

For the IPC and the Evidence Act, a heading is kept only when the Act's printed arrangement of sections agrees with the section head in the body; the few that could not be corroborated were left out rather than guessed. Every downloaded file's SHA-256 is recorded, published spellings are kept as published, and 70 spot checks (14 per Act) were compared by eye with the rendered official PDF: 70 of 70 matched.

**CrPC is catalog-only.** India Code holds the CrPC only as a scan of the Act as enacted in 1974. Its text layer is noisy OCR, it lacks sections inserted later (such as 41A and 436A), and its headings are margin notes that a second reading cannot confirm. A retry through the Legislative Department's site found no official machine-readable copy either. CrPC sections therefore keep the section catalog's title or stay unverified.

## Derived data

- **Cited sections** for each judgment are extracted by deterministic rules, with the chunk that supports each one.
- **IPC-BNS mapping flags.** Each mapping row also shows the official headings of its IPC and BNS sections. Nine CYTRAIN rows whose description conflicts with the official heading are flagged; the descriptions are kept as published.
- **Outcomes** (conviction status, appeal result, disposition) are extracted by conservative rules from the operative part of each judgment. They are unreviewed until a qualified reviewer imports a review file.

## What is never collected

- User uploads are not added to the corpus or any index.
- No API credentials, secrets or user data are stored in the repository.
